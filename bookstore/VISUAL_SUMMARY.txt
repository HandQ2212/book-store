⚠️ TROUBLESHOOTING:

   Vấn đề: "Cannot resolve method" trong IDE
   └─→ Giải pháp: IDE cache, chạy vẫn được!
       • File → Invalidate Caches → Restart
       • Hoặc cứ build và chạy thôi

   Vấn đề: Admin mới không thấy user
   └─→ Nguyên nhân: Dữ liệu chat cũ chưa migrate
       • Chạy migrate_chat_data.sql
       • Hoặc xóa: TRUNCATE TABLE chat_message;

   Vấn đề: Build failed
   └─→ Giải pháp: Clean và rebuild
       • mvnw clean compile
       • mvnw clean install

   Vấn đề: WebSocket không connect
   └─→ Kiểm tra: Network tab trong F12
       • Phải thấy ws://localhost:8080/ws
       • Status: 101 Switching Protocols
